EXPLICIT BOUNDARIES

这个页面能说明什么，也明确不假装什么

当前公开页面是只读运行门户。它验证发布身份和依赖状态， 不承载身份认证后的业务操作，也不把开发环境 Header 鉴权暴露到公网。

  • 01
    单节点，不是 HA

    用于当前受约束环境的真实功能验证，不代表生产高可用能力。

  • 02
    Scanner 保持 fail-closed

    结构检查模式会让 readiness 保持 503，health 仍可证明服务存活。

  • 03
    业务 API 默认拒绝

    匿名公网仅开放页面、静态资源、health 与 ready。
