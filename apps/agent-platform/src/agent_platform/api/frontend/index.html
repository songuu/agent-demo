EXPLICIT BOUNDARIES

这个页面能说明什么，也明确不假装什么

页面提供真实控制台，但业务 API 必须通过 operator token 或企业 JWT。 凭据不写入浏览器存储；服务端仍执行租户、Scope、Step-up 与策略门禁。

  • 01
    单节点，不是 HA

    用于当前受约束环境的真实功能验证，不代表生产高可用能力。

  • 02
    Scanner 保持 fail-closed

    结构检查模式会让 readiness 保持 503，health 仍可证明服务存活。

  • 03
    业务 API 令牌门禁

    匿名请求返回 401；仅显式认证身份可以进入治理操作链路。
